Langmuir Probe and Waves Instrument (LPW)
Derived PDS Archive Bundle
LID = urn:nasa:pds:maven.lpw.derived

Bundle Description
==================

Overview
--------
This bundle contains data which have been derived from other data products or 
determined by fits to other data. These are science quality data produced by 
the LPW instrument. The data include densities, temperatures, and Poynting 
flux. The data have been provided by the LPW team in CDF files.

Bundle Contents
===============

Collections
-----------
This bundle includes the following collections:

   * w-n - electron density derived from the Langmuir line in the passive and 
     active spectra
     (LID = urn:nasa:pds:maven.lpw.derived:data.w.n)

   * lp-nt - electron temperature and density derived from the IV-curves 
     (lpw.calibrated:data.lp.iv) and, when available, adjusted based on wave 
     derived electron density (lpw.derived:data.w.n). These products include
     the following parameters:
      1) Floating potential between spacecraft probe and ambient plasma (
         including photoelectrons) (u0)
      2) Potential between spacecraft and second product (u1)
      3) Spacecraft potential (Vsc)
      4) Electron density, total (ne)
      5) Electron density population 1 (ne1)
      6) Electron density population 2 (ne2)
      7) Electron temperature mean (Te)
      8) Electron temperature population 1 (Te1)
      9) Electron temperature population 2 (Te2)
     10) Density proxy based on spacecraft potential (nsc)
     (LID = urn:nasa:pds:maven.lpw.derived:data.lp.nt)

   * document - documents related to the MAVEN LPW derived data bundle
     (LID = urn:nasa:pds:maven.lpw.derived:document)

Data File Naming
----------------
Data files in this bundle are named according to the following convention:

   mvn_lpw_<level>_<desc>_<yyyy><mm><dd>_v<xx>_r<yy>.cdf
   
where:

   <level>  = MAVEN processing level of the data
   <desc>   = A descriptor used to identify the data file type
   <yyyy>   = 4-digit year of data coverage date
   <mm>     = 2-digit month of year of data coverage date
   <dd>     = 2-digit day of month of data coverage date
   <xx>     = 2-digit software version
   <yy>     = 2-digit data file version under the specified software version
