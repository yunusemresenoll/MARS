This file, ERRATA.TXT, contains release notes and errata concerning the
MSL REMS EDR archive.

During the course of the MSL mission the REMS science team may update
previously released data products or documentation; for example, updates may
occur due to changes in calibration data or procedures. Updates will be
reported in this file. Older versions of data and documentation will not be
retained in the archive.

Section A of this file contains an entry for each MSL release with
general information about the contents of the release, in order from newest
to oldest.  Updates to previously released files are reported in these
entries, along with any known errata.

Section B of this file contains general notes, if any, concerning the archive
as a whole.

This release has a format change applied only to the new released data: columns
whose values cannot be determined (due to reasons such as sensor damage,
saturation, etc) will no longer be "UNK" or "NULL".  Instead, they will have a
special value, which will be -999.  Depending on the given column format
definition, this may be -999.00 or -9.990E+02. For the particular case of
THERMOPILE_[A..C]_BETA columns, it will be 9.00.

The reason for this change is to ensure compatibility with PDS4. All data in
the archive, as well as the relevant documentation, will be updated for the
next release.

RELEASE NUMBER: 4
RELEASE DATE: 2013-12-13
DATA COVERAGE: 2012-08-06 to 2013-08-10 (Sols 0-359)
PRODUCT TYPES RELEASED FOR THIS ARCHIVE: REMS RDR
PRODUCT TYPES UPDATED FOR THIS ARCHIVE: REMS RDR

All REMS RDR products from Sols 0 through 269 have been revised and
re-released in order to correct errors and to add new data. The list
of updates can be found below. As in the previous releases, revised
products can be identified by an increment in the label keywords
PRODUCT_VERSION_ID and PRODUCT_CREATION_TIME.

List of changes:

 1. Added Humidity Sensor ENVRDR and MODRDR data. The relative
    humidity in MODRDR level has been divided into local relative
    humidity and atmospheric relative humidity. Atmospheric relative
    humidity has been set to NULL pending further revision.
 2. Calibration parameters have been updated for GTS and PS. Data from
    these sensors have changed as a result of this. For PS this
    happens only from sol 276 onwards.
 3. GTS systematic uncertainties are now divided into absolute (long term)
    uncertainty and relative (short term) uncertainty.
 4. Rover movement flag in GTS confidence level code flipped (now is 
    0 = moving, 1 = still).
 5. SPICE kernels provided by NAIF used for processing have been
    updated. This has an impact in position and time dependent data.
 6. Width field changes in ADR_GEOM.FMT for the rover positions
    columns (ROVER_POSITION_X, ROVER_POSITION_Y, ROVER_POSITION_Z)
 7. Updates in rover velocity processing to minimize noise and to
    remove spurious data.

RELEASE NUMBER: 3
RELEASE DATE: 2013-06-20
DATA COVERAGE: 2012-08-06 to 2013-05-09 (Sols 0-269)
PRODUCT TYPES RELEASED FOR THIS ARCHIVE: REMS RDR
PRODUCT TYPES UPDATED FOR THIS ARCHIVE: REMS RDR

The following errors have been detected in this dataset. They will be
corrected in the next release.
 
List of errors:

 1. In MODRDR the columns BOOM1_LOCAL_AIR_TEMP, BOOM2_LOCAL_AIR_TEMP
    and AMBIENT_TEMP are in Celsius degrees instead of Kelvin as the 
    format file indicates.
 2. The flag 'Wind Sensor status' value is swapped for Air Temperature 
    Sensor confidence levels (WS ON is marked as 0 instead of 1, and
    WS OFF is marked as 1 instead of 0). This error concerns the columns
    ATS_BOOM1_CONFIDENCE_LEVEL and ATS_BOOM2_CONFIDENCE_LEVEL in ENVRDR
    and ATS_BOOM1_CONFIDENCE_LEVEL, ATS_BOOM2_CONFIDENCE_LEVEL and
    AMBIENT_TEMP_CONFIDENCE_LEVEL in MODRDR.

All REMS RDR products from Sols 0 through 179 have been revised and
re-released. The list of updates can be found below. As in the previous
release, revised products can be identified with the label keywords
PRODUCT_VERSION_ID and PRODUCT_CREATION_TIME.

List of changes:

 1. Added Air Temperature Sensor MODRDR data.
 2. Corrected rover position and velocity data in ADRs which were
    mistakenly set to 0. Data dependent on these factors (such as rover 
    motion flags in confidence levels or MODRDRs UV data) were affected.
 3. A new confidence level flag in Wind Sensor data indicates whether its 
    configuration was correctly selected based on measured air temperature.
 4. New confidence level flag for the Ground Temperature Sensor that takes
    shadows in its field of view into account.
 5. Change on the saturation limit for convective powers in Wind Sensor. 
 6. Calibration parameters for the Pressure sensor have been updated.
 
RELEASE NUMBER: 2
RELEASE DATE: 2013-06-20
DATA COVERAGE: 2012-08-06 to 2013-02-06 (Sols 0-179)
PRODUCT TYPES RELEASED FOR THIS ARCHIVE: REMS RDR
PRODUCT TYPES UPDATED FOR THIS ARCHIVE: REMS RDR

All REMS RDR products from Sols 0 through 89 have been revised and
re-released. Revisions were made to correct errors discovered in the
data processing and to update confidence level codes. Revised products
may be identified by the label keyword PRODUCT_VERSION_ID, which will
have a value greater than 1.0, by the keyword PRODUCT_CREATION_TIME,
which will have a value later than the previous release date of
February 6, 2013, and by the version number in the filename, which
will be greater than 1.

List of changes:
 1. Corrected a processing error in UV sensor in ENVRDRs, in which
    when the Solar Zenith Angle was between 20 and 30 degrees UV
    radiation was processed as diffuse radiation instead of as direct
    radiation.
 2. The time drift of 3 seconds has been corrected.
 3. SOLAR_AZIMUTH column in ADR_GEOM1.FMT has been renamed to
    SOLAR_LONGITUDE_ANGLE. SOLAR_ELEVATION column in the same file has been 
    renamed to SOLAR_ZENITHAL_ANGLE.
 4. ASIC Noise flag in Wind Sensor confidence level now occupies two 
    characters.
 5. New flag in Pressure Sensor confidence level to take into account
    the oscillator being used.
 6. Ultraviolet confidence level in MODRDR now includes a dust sensor
    degradation flag.
